# Get multiscale level for a variable

Get multiscale level for a variable

## Usage

``` r
get_var_level(
  var,
  h_info,
  equations = NULL,
  latent = NULL,
  categorical_vars = NULL
)
```

## Arguments

- var:

  Variable name

- h_info:

  Hierarchical information list

- equations:

  Optional list of equations

- latent:

  Optional character vector of latent variables

- categorical_vars:

  Optional character vector of categorical variables

## Value

Character level name or NULL
