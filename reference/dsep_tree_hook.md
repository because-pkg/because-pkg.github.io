# D-Sep Tree Hook

Backward-compatible alias for
[`dsep_structure_hook`](https://because-pkg.github.io/because/reference/dsep_structure_hook.md).

## Usage

``` r
dsep_tree_hook(structure, test_eq, hierarchical_info, levels, ...)
```

## Arguments

- structure:

  The structure object.

- test_eq:

  The current d-separation test equation.

- hierarchical_info:

  Hierarchical metadata.

- levels:

  Level mapping.

- ...:

  Additional arguments.

## Value

The tree object or NULL.
