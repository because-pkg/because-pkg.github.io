# Get precision prior by family

Get precision prior by family

## Usage

``` r
get_precision_prior(param_name, var_name, priors = NULL, family = NULL)
```

## Arguments

- param_name:

  Name of the parameter

- var_name:

  Name of the variable

- priors:

  Named list of custom priors

- family:

  Named vector/list of response families

## Value

Formatted BUGS precision prior statement
