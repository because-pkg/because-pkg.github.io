# Execute full NIMBLE pipeline (sequential or parallel) for because()

Execute full NIMBLE pipeline (sequential or parallel) for because()

## Usage

``` r
run_nimble_pipeline(
  model_string,
  data,
  family,
  extension_inits,
  monitor,
  n.chains,
  n.iter,
  n.burnin,
  n.thin,
  WAIC,
  nimble_samplers,
  parallel,
  n.cores,
  cl = NULL,
  quiet = FALSE
)
```
