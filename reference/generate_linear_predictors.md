# Generate linear predictors for JAGS/BUGS model

Constructs the systematic linear predictors (mui \<- ...) across
equations for all supported distributions (Gaussian, Binomial, Poisson,
Multinomial, Ordinal, Negative Binomial, ZIP, ZINB, Occupancy).

## Usage

``` r
generate_linear_predictors(ctx)
```

## Arguments

- ctx:

  Builder context environment
